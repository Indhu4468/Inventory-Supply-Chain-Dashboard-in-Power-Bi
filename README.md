# Inventory-Supply-Chain-Dashboard

## Project Overview
This Power BI project analyzes inventory and supply chain operations to monitor sales trends, shipping delays, delivery risks, and product performance.

## Tools Used
- Power BI
- Power Query
- DAX
- Data Modeling

## Business Problems
- No visibility into sales trends
- Shipping delays affecting customer satisfaction
- Difficulty tracking late delivery risks
- Poor inventory and demand alignment

## Key Features
- Monthly Sales & Profit Analysis
- Shipping Delay Monitoring
- Late Delivery Risk Tracking
- Product Performance Analysis
- Category-wise Sales Insights

## Data Model
- Star Schema
- Fact_Orders
- Dim_Products
- Dim_Category
- Dim_Date

## Key DAX Measures
- Total Sales
- Total Profit
- Late Delivery %
- Average Shipping Delay

## Dashboard Pages
1. Overview Dashboard
2. Supply Chain & Shipping Overview
3. Product Performance Analysis
